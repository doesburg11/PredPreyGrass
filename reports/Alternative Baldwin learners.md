# Linear SARSA Offers the Cleanest Alternative

**Implement linear SARSA(λ) next, but treat it as a new value-based Baldwin condition rather than a drop-in optimizer.** It is the only candidate examined here that changes both the learned object—from policy logits to action values—and the credit mechanism—from an immediate score-function update to bootstrapped temporal-difference learning with eligibility traces. Linear actor–critic is a useful diagnostic bridge, but its actor is still the same policy-gradient family as the current learner. Reward-modulated plasticity is biologically motivated, yet the repository’s action-credited version is mathematically close to an eligibility-trace policy gradient, while genuinely different local rules introduce more arbitrary design choices and have already struggled with action credit. The repository can preserve a clean Baldwin boundary by using inherited action parameters only to initialize each newborn’s Q function, then keeping lifetime Q changes and traces private and non-heritable. The decisive caveat is the reward `r_t = E_t - E_{t-1}`: discounting changes its meaning, and death currently lacks a defined terminal evaluation, so both `γ` and terminal handling are scientific factors rather than implementation details. A fair first experiment should therefore compare the current learner, SARSA(0), and SARSA(λ) on matched founders and seeds, while holding the ecology and inherited evaluator fixed and declaring behavioral and numerical success criteria before a long evolutionary run.

## SARSA changes the scientific mechanism; actor–critic does not

The current repository rule applies the scalar evaluation change directly to the sampled action’s softmax score, approximately `θ ← θ + α(E_t-E_{t-1})∇log πθ(a|s)`. Repository inspection, rather than literature, establishes that it has no return-to-go or learned critic and is therefore best described as an immediate-reinforcement policy-gradient rule, not canonical episodic REINFORCE ([local `networks.py`](/home/doesburg/Projects/PredPreyGrass/predpreygrass/evolutionary/eco_evolutionary_erl_baldwin/networks.py)). **Linear SARSA(λ) is scientifically distinct because it learns `Q(s,a)`, selects behavior from those values, and updates them with `δ_t = r_{t+1}+γQ(s_{t+1},a_{t+1})-Q(s_t,a_t)` and an action-conditioned trace.** SARSA is the on-policy control counterpart of TD(λ), and linear action-block features are an established route from discrete-state control to continuous inputs ([Rummery & Niranjan](https://citeseerx.ist.psu.edu/document?doi=7a09464f26e18a25a948baaa736270bfb84b5e12&repid=rep1&type=pdf); [van Seijen et al.](https://arxiv.org/abs/1512.04087)). This distinction is operational, not a promise of convergence: fixed-policy linear TD has strong results, but changing-policy linear SARSA has guarantees only under restrictive conditions and can remain in a bounded “chattering” region ([Tsitsiklis & Van Roy](https://web.mit.edu/~jnt/www/Papers/J063-97-bvr-td.pdf); [Zhang, Tachet des Combes & Laroche](https://arxiv.org/abs/2202.06828)). The ecology is also partially observed and nonstationary, so those theorems do not describe this simulation.

Linear actor–critic is a worthwhile secondary control, not the primary alternative. Its critic would learn `V_w(s)` and replace the current scalar modulator with `δ_t = r_{t+1}+γV_w(s_{t+1})-V_w(s_t)`, but the actor still takes `θ ← θ+αδ_t∇log πθ(a_t|s_t)`. The policy-gradient theorem explicitly places REINFORCE and actor–critic in the same family, while actor–critic’s benefit is a learned, bootstrapped estimate that can reduce variance and add predictive temporal credit ([Sutton et al.](https://papers.neurips.cc/paper_files/paper/1999/file/464d828b85b0bed98e80ade0a5c43b0f-Paper.pdf); [Konda & Tsitsiklis](https://papers.nips.cc/paper_files/paper/1999/file/6449f44a102fde848669bdd9eb6b76fa-Paper.pdf)). It cleanly tests whether a state-dependent baseline and prediction error rescue the existing actor, especially at `γ>0`; at `γ=0` it is mainly a variance-reduced version of the present mechanism. Its actor–critic decomposition and global TD-like modulation have plausible neuroscientific analogies, but the exact linear architecture and global scalar update remain engineering abstractions, so “biologically inspired” is the defensible claim ([Joel, Niv & Ruppin](https://doi.org/10.1016/S0893-6080(02)00047-3)).

Reward-modulated three-factor plasticity is likewise an established learning family: local pre/post activity establishes eligibility, and a later reward-like third factor consolidates change over behavioral delays ([Gerstner et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC6079224/); [Florian](https://direct.mit.edu/neco/article/19/6/1468/7190/Reinforcement-Learning-Through-Modulation-of-Spike)). But the repository’s current action-credited plasticity uses `one_hot(action)-probs`, the softmax log-policy derivative, before applying the trace through evolved per-connection `alpha`; replacing random-sign alpha with a positive global rate removes the scrambling but yields an eligibility-trace policy gradient, not an independent algorithm ([repository implementation](https://github.com/doesburg11/PredPreyGrass/blob/3bf8443443c990b335c31d6fa06cff377a9df8a2/predpreygrass/evolutionary/eco_evolutionary_erl_baldwin_hebbian/networks.py#L106-L145)). A shared evolved Hebbian/Oja/BCM-style rule would be more distinct and avoid independent random signs, yet there is no canonical rule for this four-action linear softmax, and plain pre×post correlation lacks sampled-action credit. Published differentiable-plasticity successes optimize plasticity coefficients across tasks rather than assuming useful random founder signs ([Miconi, Stanley & Clune](https://proceedings.mlr.press/v80/miconi18a.html)); evolution can indeed discover useful local rules, but that evidence supports an expensive outer-loop hypothesis, not immediate first-generation competence ([Najarro & Risi](https://papers.nips.cc/paper/2020/hash/ee23e7ad9b473ad072d57aaa9b2a5222-Abstract.html)).

## Inheritance stays Darwinian when lifetime state remains private

The repository already contains the necessary separation: newborn live action parameters are copied from `Genome`, and reproduction constructs offspring from genomic rather than lifetime-modified parameters ([repository birth and reproduction paths](https://github.com/doesburg11/PredPreyGrass/blob/main/predpreygrass/evolutionary/eco_evolutionary_erl_baldwin/world.py#L398-L411)). For SARSA, retain `genome.action_weights` and `genome.action_bias` as inherited **initial Q parameters**, copy them to a live `θ_life` at birth, and zero a same-shaped eligibility trace `e_life`. Only `θ_life` and `e_life` change during an individual’s life; crossover, mutation, lineage metrics, and reproduction continue to read the genome. This preserves Darwinian inheritance but changes the semantic meaning of the inherited matrix from policy logits to initial action values, which must be explicit in plots and claims. Genetic assimilation is then evidence that inherited Q initialization improves while the counterfactual fitness gap between lifetime learning enabled and disabled declines—not merely that action-site mutation slows.

Actor–critic has an equally clean boundary: genomic action weights initialize the live actor, while a zero-initialized critic vector, critic bias, and optional traces exist only in the agent. A shared evolved plasticity rule instead places its small rule coefficients in the genome while keeping traces and effective weight changes lifetime-only. That is still Darwinian, but it asks a different outer-loop question: whether evolution discovers a learning rule. In every candidate, checkpoint serialization may preserve live state for exact run continuation, but that operational persistence must never become biological inheritance.

Repository-derived inference also requires splitting the current genetic metrics. Base action/Q genes, evaluation genes, and any plasticity-rule genes need separate site-change rates; pooling base weights with alpha coefficients cannot distinguish policy assimilation from learning-rule optimization. Within-life diagnostics must measure actual parameter displacement and induced action-value or logit displacement on encountered observations, action entropy and argmax switches, update and trace norms, and performance with lifetime state enabled versus zeroed. **Trace magnitude alone does not establish a behavioral effect.**

## Difference rewards make gamma and death experimental factors

The inherited evaluator supplies `r_{t+1}=E(s_{t+1})-E(s_t)`. Algebra, not outside literature, determines the central semantic constraint: at `γ=1`, a finite-life return telescopes to `E(s_T)-E(s_0)`; at `γ<1`, `Σγ^k(E_{t+k+1}-E_{t+k}) = -E_t +(1-γ)Σγ^{j-1}E_{t+j}`, so intermediate evaluation levels acquire positive weight. **Gamma therefore changes the objective; it is not just a stability knob.** For actor–critic, an average-reward formulation is particularly ill-suited because the long-run mean of a bounded temporal difference tends toward zero. For SARSA, preregister `γ=1` as the endpoint-improvement interpretation and one moderate value such as `0.9` as an explicitly different, recency-weighted objective. SARSA(0) should use the same `γ` values so λ’s contribution can be isolated.

Death exposes a gap in the current loop: a dead agent may never reach the next normal update, and there is no documented terminal observation. SARSA and actor–critic require exactly one terminal transition with zero bootstrap, but `δ_terminal = r_terminal-Q(s_t,a_t)` is undefined until the experiment specifies `r_terminal`. The least confounded first implementation should define an absorbing terminal evaluation `E_terminal` and set `r_terminal=E_terminal-E(s_t)`, using the same documented constant for all agents and algorithms; choosing `E_terminal=0` is simple only if evaluator output zero has a stable meaning. A fixed extra death penalty would add information unavailable to the baseline and should therefore be a separate reward-semantics factor, not silently embedded in SARSA. If strict baseline compatibility is the priority, run a paired “legacy omission” condition where all learners omit the fatal update, but do not mistake that condition for correct terminal TD learning.

The exact nonterminal SARSA ordering is also consequential. After observing `s_{t+1}`, compute `r_{t+1}`, sample and cache `a_{t+1}` from the live behavior policy, calculate the TD error using that same action, update the trace and Q parameters, and then execute the cached action. Resampling after the update means the target action and behavior action differ, so the code is no longer literal SARSA. Use `x=[obs;1]`, `Q(s,a)=xᵀθ_a`, `e←γλe+φ(s,a)`, and `θ←θ+αδe`; at terminal, bootstrap with zero and clear `e`. A fixed-temperature softmax-over-Q is preferable for the first comparison because it retains the baseline’s smooth stochastic action family, although it is still a substantive policy change and entropy must be measured. Epsilon-greedy is more canonical but adds discontinuous tie handling and a larger exploration confound.

## A staged matched-seed test can falsify SARSA cheaply

Implementation should touch the smallest coherent surface. In `networks.py`, add linear Q calculation, fixed-temperature action sampling, and a SARSA update helper. In `Agent`, add lifetime eligibility state plus cached previous observation/action; founder and newborn construction must copy genomic Q parameters and zero the trace. In `_step_agents`, reorder selection and updating so the next action is sampled once and cached. Every removal/death path must issue at most one terminal update. Configuration and checkpoints need algorithm, `α`, `γ`, `λ`, temperature, live Q, trace, and random-generator state when exact continuation is promised. Unit tests should hand-check one- and two-transition updates, selected-action block locality, cached-target identity, one-time zero-bootstrap termination, zero traces at birth, noninheritance of live Q/traces, no updates when learning is disabled, deterministic tie/sampling behavior, and checkpoint continuation.

The minimal experiment is deliberately staged. First, on fixed founders and frozen/single-agent trajectories, compare the existing immediate policy-gradient learner, SARSA(0), and SARSA(λ), plus learning-off copies, using identical observations, evaluator, transitions, and random streams where feasible. Measure evaluation change, survival/evasion proxies, entropy, argmax switches, `|δ|`, Q/trace/update norms, and learned-minus-genomic displacement by age. Sweep a small preregistered grid on development seeds—log-spaced `α`, `λ∈{0,0.5,0.9}`, `γ∈{1,0.9}`, and two fixed temperatures selected to bracket baseline entropy—then freeze one setting per algorithm before held-out seeds. Reject configurations with non-finite values, persistent parameter growth beyond a declared norm ceiling, or action collapse caused only by a mismatched temperature.

Second, run short matched-seed population smoke tests in the repository’s existing ERL, E, L, F, and Brownian conditions, adding SARSA(0) to isolate trace credit and a lifetime-state-zeroed evaluation for the selected SARSA(λ). Keep founder genomes, environment seeds, evaluator, ecology, mutation schedule, and tuning budget fixed; report extinction and censored runs rather than dropping them. Only if SARSA passes should it enter the expensive multi-generation comparison, with separate inherited-Q and evaluator site-change metrics, lineage lifetime and offspring outcomes, and the learned-state-enabled versus zeroed fitness gap across generations. A frozen-founder-initial-Q treatment can further distinguish evolution of priors from learning alone.

**Acceptance requires more than one favorable seed.** Advance SARSA(λ) if, on held-out seeds, it remains numerically stable, produces a reproducible within-life performance gain over its learning-off twin, and exceeds both SARSA(0) and the current learner on a preregistered primary outcome with an uncertainty interval that excludes a practically negligible effect. Because pilot variance is not yet known, the effect threshold and seed count must be set after a variance-only pilot, before examining treatment differences. The mechanism is supported only if TD updates precede useful action changes and zeroing lifetime Q changes removes the gain. Falsify the trace hypothesis if SARSA(λ) does not improve on SARSA(0); falsify SARSA as a useful replacement if it cannot beat learning-off after fair tuning, is dominated by the current learner on held-out seeds, or its apparent gain disappears after entropy matching. Stop before a long evolution run if any of those criteria hold.

## Conclusion

Linear SARSA(λ) is the strongest next test because it buys genuine algorithmic independence without changing the observation model or adding a large neural architecture. Its main cost is conceptual honesty: inherited action parameters become Q priors, while `γ`, behavior-policy temperature, and terminal evaluation become visible parts of the scientific treatment.

The most informative outcome is not necessarily a win. If SARSA(0) succeeds but SARSA(λ) does not, the ecology favors bootstrapping over extended backward credit; if actor–critic later succeeds where SARSA fails, the existing stochastic actor representation matters more than value control; if neither succeeds, the likely ceiling is the evaluator/reward semantics or partial observation rather than the optimizer. That staged logic turns the implementation into a discriminating experiment instead of another tuning branch.
